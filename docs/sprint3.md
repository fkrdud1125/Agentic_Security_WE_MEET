# Sprint 3 — 커밋 자동 감지와 변화 추적

v6 계획의 Sprint 3 목표는 “커밋하는 순간 새 취약점이 대시보드에 뜸”이다. 발견 지문(`fingerprint`)이 필요해 `feat/diagnosis-hardening` 위에서 진행한다.

## 1단계: 발견 변화 추적과 위험 점수 추이

- [x] 같은 레포의 직전 스캔 결과와 발견 지문을 비교해 new / existing / fixed 판정, `introduced_in`(처음 발견 커밋) 기록
- [x] 사라진 발견은 `fixed` 항목으로 결과에 남기고 위험 점수·요약에서는 제외. 보고서에 ‘직전 스캔 대비’ 줄과 ‘직전 스캔 이후 해결됨’ 섹션
- [x] 같은 지문이 여러 개면 개수대로 짝지음. 이번에 파싱하지 못한 파일의 이전 발견은 해결로 보지 않고 유지
- [x] 지문이 없는 구버전 결과는 비교하지 않음(`비교 전`). 직전 결과 파일이 없거나 손상되면 그보다 오래된 결과와 비교하고 그 커밋을 기준으로 기록
- [x] 대시보드: 커밋 변화 카드(`+새 / −해결`, 기준 커밋), 위험 점수 타일의 최근 12회 추이 스파크라인(0~100 고정 축, 점 hover 시 커밋·점수), 발견 상세의 처음 발견 커밋

변경분만 검사하는 Semgrep `--baseline-commit` 대신 매번 전체를 검사하고 직전 결과와 비교한다. 자체 탐지기(시크릿·설정·라우트) 결과까지 같은 기준으로 비교되고 코드가 짧다. 큰 레포에서 느려지면 변경 파일만 검사하는 방식으로 바꾼다.

## 2단계: 커밋 후 자동 스캔 (git post-commit hook)

- [x] 대시보드의 ‘커밋 후 자동 스캔 켜기/끄기’로 레포의 `.git/hooks/post-commit` 설치·해제
- [x] hook은 `vibescan hook-trigger`를 백그라운드로 실행해 커밋을 지연시키지 않음(실측 약 0.15초). hook을 설치한 코드 위치를 `PYTHONPATH`로 고정
- [x] hook-trigger는 대시보드와 무관하게 정적 검사만 실행해 기본 결과 폴더와 이력 DB에 저장(`trigger: git-hook`). 대시보드가 꺼져 있어도 결과가 쌓임
- [x] 연속 커밋: 3초 기다린 뒤 HEAD가 바뀌었으면 건너뛰어 마지막 커밋만 검사
- [x] 연결하지 않은 레포에서 hook이 실행되면 검사하지 않음. 백그라운드 실패는 설정 폴더의 `hook.log`에 한 줄 기록
- [x] 다른 post-commit hook이 있거나 `core.hooksPath`를 쓰는 저장소는 덮어쓰지 않고 직접 추가할 한 줄을 안내. 해제는 VibeScan이 만든 hook만 삭제
- [x] GitHub 주소로 연결한 레포(VibeScan 전용 clone)에는 설치하지 않음
- [x] 대시보드는 10초마다 가장 새 결과 폴더만 확인하고, 새 결과가 생기면 자동으로 열어 알림

`--results`로 다른 결과 폴더를 연 대시보드에는 hook 결과(기본 폴더에 저장)가 나타나지 않는다.

## 검증

- 전체 단위 테스트 69개 중 68개 통과, 심볼릭 링크 권한이 필요한 1개 건너뜀. `node tests/test_dashboard_ui.cjs` 통과.
- 실제 Git·Semgrep으로 세 번 스캔: 첫 스캔 비교 전 → 비밀값 변경 시 새 1·해결 1(점수에서 해결 제외) → 무관한 커밋 시 기존 1과 처음 발견 커밋 유지.
- 비교 단위 테스트: 중복 지문, 파싱 실패 파일 유지, 구버전 결과 비교 거부, 이전 결과 불변.
- 브라우저: 데모 레포에서 커밋을 바꿔 가며 스캔해 새 1·해결 2 판정, 4회 추이 스파크라인과 커밋 변화 카드 확인.
- hook: 실제 `git commit`이 대기 시간보다 빨리 끝나고 백그라운드 결과가 `git-hook`으로 저장됨, 다른 hook·`core.hooksPath` 보존, 연결 안 된 레포·이전 커밋 건너뜀, 실패 로그.
- 브라우저: 자동 스캔 켜기 → 터미널 커밋(0.15초) → 몇 초 뒤 결과 자동 표시와 해결 3건·추이 갱신. 결과가 하나도 없는 상태에서 첫 hook 결과를 놓치던 버그를 이 확인 중 발견해 수정하고 UI 테스트로 고정.
