레포 연결

ChatGPT 연결 상태를 확인하는 중입니다.

현재 HEAD의 전체 정적 검사입니다. 미커밋 변경은 제외합니다. GitHub 주소로 연결한 레포는 스캔 전에 최신 커밋을 가져옵니다. Git 저장소가 아닌 일반 폴더는 스캔할 때마다 현재 파일을 스냅샷으로 기록해 검사하며, 폴더 자체는 바꾸지 않습니다.
커밋 후 자동 스캔을 켜면 이 레포에서 커밋할 때마다 백그라운드에서 정적 검사가 실행되고, 결과가 이 화면에 자동으로 나타납니다.
ChatGPT 분석을 선택하면 비밀값을 가린 코드 일부를 OpenAI로 보내며, 내 ChatGPT 구독 사용량이 차감됩니다.
